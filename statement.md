⦁	Problem statement

The BMI is a numerical value that indicates whether a person is underweight, normal weight, overweight, or obese.

*Requirements*

1. The program should *ask the user* to input:

   * Weight (in kilograms)
   * Height (in meters)

2. The program must *compute BMI* using the formula:
   [
   \text{BMI} = \frac{\text{weight}}{\text{height}^2}
   ]

3. After calculating BMI, the program should *categorize the result* based on the BMI value:

   * *Underweight:* BMI < 18.5
   * *Normal weight:* 18.5 ≤ BMI < 24.9
   * *Overweight:* 25.0 ≤ BMI < 29.9
   * *Obesity:* BMI ≥ 30.0
